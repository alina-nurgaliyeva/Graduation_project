# Stets Home — Smart Home Management Application

Project Overview:

Stets Home is a conceptual smart home management application designed to help users monitor and control connected home devices through a single interface.

The goal of this project was to analyze the requirements and design the structure and functionality of the proposed application.


Project Objectives: 
- Identify the needs and expectations of potential users.
- Define functional and non-functional requirements.
- Model business processes and system interactions.
- Design the application’s data structure.
- Develop a user interface prototype.
- Prepare testing documentation.

Project Deliverables:
- Requirements specification
- User Stories and User Story Map
- Context and Logical DFD diagrams
- ER Diagram and Data Dictionary
- UI Structure Diagram
- Prototype in Figma
- Test Plan and Test Cases

Tools & Technologies:
- Figma
- UML
- BPMN
- DFD
- ERD
